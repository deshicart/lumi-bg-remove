━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. removeBackground (Cloud Function)
   - Accepts base64 image data
   - Validates user authentication
   - Checks daily usage limit
   - Calls Remove.bg API
   - Uploads result to Firebase Storage
   - Updates usage counter
   - Returns processed image URL
   - Error handling in Bengali

2. trackAdWatch (Cloud Function)
   - Validates user authentication
   - Increments ad watch counter
   - Grants +1 extra usage
   - Updates Firestore document
   - Returns success status

3. getUserUsage (Cloud Function)
   - Retrieves daily usage data
   - Returns count, ad watches, remaining
   - Handles Bangladesh timezone
   - Auto-creates if doesn't exist
